Dynamics 365 Business Central: Apply line discounts and fees on contract lines

This feature lets you define discount and fee percentages on a quotation or contract line. When a transaction is generated and approved, the system applies the discount or fee, updates actuals, and applies the amounts during invoicing. A discount reduces the line total, while a fee increases it. Quotation values carry over to contract lines.

Status: Launched | GA Date: September CY2026 | Preview Date: September CY2025 | Roadmap Status: Include this month

Products: Dynamics 365 Project Operations

Cloud: Worldwide (Standard Multi-Tenant)

Platforms: Web

Dynamics 365 Project Operations: Transaction Journals

Transaction journals let users author complete time, expense, and material transactions—including different transaction classes within the same journal. Users enter transactions through a dedicated Transactions tab and select Preview to generate and review the journal lines and relationships that will be created.

When the journal is confirmed, Project Operations creates the applicable cost, unbilled-sales, and inter-organizational actuals, along with the required relationships between them, without creating an approval record or initiating an approval workflow. The confirmed journal is then locked using the existing journal behavior, and resulting actuals can be corrected through the existing correction-journal process.

Status: In development | GA Date: March CY2027 | Roadmap Status: Include this month

Products: Dynamics 365 Project Operations

Dynamics 365 Project Operations: Optimize, discover and manage features from one place

A single place in Project Operations where administrators and end users can discover the core features relevant to them in lite or resource/non-stocked deployments.

**For administrators: **

  • Browse features by status: New, Available, Enabled, or Coming soon.
  • Filter and search by product area.
  • Review benefits, impact, dependencies, availability timing, and guidance.
  • Check whether a feature is optional or automatically enabled and whether it can be reversed.
  • Receive advance notice of upcoming features through notifications and a banner.

**For end users: **

  • View newly available and enabled features.
  • Access task-level guidance through Learn more.
  • Receive notifications on features newly available in the product
