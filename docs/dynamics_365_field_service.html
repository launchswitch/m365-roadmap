Dynamics 365 Field Service: Automatically complete Project Tasks when field work is finished

Keep project plans aligned with field execution by automatically completing a linked Project Task when its Work Order is completed.

When project work is carried out through Field Service, the Work Order often represents the execution of a specific Project Task. With this capability, organizations can configure Work Order Types so that completing the Work Order also completes the associated Project Task.

Dynamics 365 Field Service: Bring project material plans into field execution

When the Field Service and Project Operations integration is enabled, material estimates created in a project plan can now create connected Work Order Products on the related Field Service work order. This allows project-planned materials to flow into Field Service without requiring project and field teams to recreate material lines, keeping both teams aligned on the same material plan.

As before, Work Order Products can create material estimates when materials are added from Field Service during execution. Supported changes remain synchronized across the project task, work order, and material line, allowing material planning to begin from either Project Operations or Field Service while keeping planning and execution aligned.

Dynamics 365 Field Service: Streamline mobile work with an optimized Subgrid control

Business Value

With a Subgrid optimized for mobile, frontline workers will experience click reduction and faster field workflows. Enhancements to the Subgrid control include top‑level Add New and Use/Complete all action buttons, bulk‑add functionality, barcode scanning, and inline editing to speed record management on the go.

Feature Details

Field Service Mobile is improving the existing Service Task View, Service View, and Product View Subgrid controls to provide a faster, touch-first way for technicians to work with common Field Service scenarios such as Work Order Products, Services, and Service Tasks.

  • Users can add multiple records in fewer steps using bulk add mutli-select functionality.
  • Users can mark all records as complete/used in one go, saving repetitive, individual clicks per record.
  • Frequently used fields for Subgrid records can be edited inline, reducing the need to open the full record form for common updates.
  • Barcode scanning helps users quickly find and select products instead of scrolling through a long list.

This experience keeps frontline workers in context by returning them directly to the grid after save, reducing navigation, scrolling, and form transitions — allowing them stay focused on their customer work.
