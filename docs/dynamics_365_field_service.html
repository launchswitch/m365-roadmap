Dynamics 365 Field Service: Streamline mobile work with an optimized Subgrid control

Business Value

With a Subgrid optimized for mobile, frontline workers will experience click reduction and faster field workflows. Enhancements to the Subgrid control include a top‑level Add New action button, bulk‑add functionality, barcode scanning, and inline editing to speed record management on the go.

Feature Details

Field Service Mobile is improving the existing Service Task View, Service View, and Product View Subgrid controls to provide a faster, touch-first way for technicians to work with common Field Service scenarios such as Work Order Products, Services, and Service Tasks.

  • Users can add multiple records in fewer steps using bulk add mutli-select functionality.
  • Frequently used fields for Subgrid records can be edited inline, reducing the need to open the full record form for common updates.
  • Barcode scanning helps users quickly find and select products instead of scrolling through a long list.

This experience keeps frontline workers in context by returning them directly to the grid after save, reducing navigation, scrolling, and form transitions — allowing them stay focused on their customer work.
