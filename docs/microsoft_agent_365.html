Microsoft Copilot (Microsoft 365): Local inferencing

Local inferencing expands Microsoft Copilot’s sovereign controls by enabling AI inferencing for supported Copilot interactions to occur within the applicable local geography.

Launching in Australia, India, the United Arab Emirates, the United Kingdom, and the United States, this capability gives organizations greater control over where AI inferencing occurs, helping them address sovereignty and regional requirements. Inferencing is the processing step when an AI model executes a prompt to produce an output or response.

Status: In development | GA Date: December CY2026 | Roadmap Status: Include this month

Products: Excel, Exchange, Forms, Microsoft 365, Microsoft 365 admin center, OneDrive, OneNote, Outlook, Planner, Word, Microsoft 365 app, Microsoft Copilot (Microsoft 365), Microsoft Agent 365

Cloud: Worldwide (Standard Multi-Tenant)

Platforms: Android, Desktop, iOS, Mac, Web

Phase: General Availability

Microsoft Agent 365: the control plane for agents

Agent 365 is the control plane for AI agents. It empowers IT and security administrators to observe, govern, and secure agents across Microsoft 365 and connected platforms at scale.

Microsoft Agent 365: Registry sync
