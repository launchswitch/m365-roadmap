Dynamics 365 Commerce: Add items to a transaction from the numpad

How it works

​
Quick add reuses the existing numpad on the transaction screen, so there is no new input control to learn and no additional space consumed in the transaction grid.
​

  1. The associate enters a full or partial item number on the numpad.
  2. On an exact match, the item is added directly to the transaction.
  3. On a partial match, instead of navigating to the search results page, an inline dialog opens on the transaction screen listing the matching products.
  4. The associate adds an item directly from that inline list using Add to sale.
    ​
    If a selected product requires variant selection such as size or color, the variant selection dialog is invoked inline before the item is added. Quick add is optimized for fast, SKU-based matching and is intentionally distinct from global search, which remains the tool for exploration and rich product discovery.
    ​

Inline result experience

​

  • Partial matches are shown as a list on the transaction screen, each row offering an Add to sale action.
  • Results do not navigate to the product page by default, keeping the associate in context.

​

Platform behavior

​

  • Desktop and mobile behave consistently: exact matches add directly, partial matches show inline results.
  • On mobile, the full-screen numpad follows the same logic.
    ​

Entry point

​
Quick add is triggered from the existing numpad on the transaction screen. There is no separate text input field, avoiding redundancy with global search and preserving screen space.
​

Enabling the feature

​

  • Application: Store Commerce (Point of Sale).
  • Quick add builds on the numpad entry experience already present on the transaction screen.
    ​

Dependencies

​

  • Reuses the inline variant selector common control, shared with the Bulk add experience.
  • Quick add and Bulk add are companion features; Bulk add covers pasting a full list of items, while Quick add covers fast single-item entry from the numpad.
